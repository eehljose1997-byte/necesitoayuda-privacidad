Política de Privacidad — Necesito Ayuda

Última actualización: 5 de octubre de 2026

1. Responsable

Necesito Ayuda es una aplicación móvil diseñada para facilitar la gestión de solicitudes de ayuda.

2. Información que recoge

La aplicación permite al usuario introducir voluntariamente:

  • Nombre completo.
  • Ciudad o municipio.
  • Número de teléfono.
  • Correo electrónico.
  • Categoría de la necesidad.
  • Descripción de la solicitud.
  • Notas adicionales.
  • Fecha de registro.

La aplicación no solicita datos biométricos, información financiera ni identificadores publicitarios.

3. Almacenamiento de datos

Los datos introducidos por el usuario se almacenan localmente en su dispositivo.

La aplicación utiliza SQLite mediante Room Database y DataStore.

Puede almacenar información del perfil, solicitudes de ayuda y preferencias de la aplicación.

4. Transmisión de datos

Necesito Ayuda no transmite datos personales a servidores remotos.

La aplicación no utiliza actualmente cuentas online, servicios de nube, publicidad, analítica ni seguimiento de usuarios.

Los datos permanecen almacenados localmente en el dispositivo.

5. Permisos

La aplicación utiliza notificaciones locales para informar al usuario sobre sus solicitudes de ayuda.

También puede utilizar la vibración para las notificaciones cuando esta opción está habilitada.

La aplicación declara los permisos técnicos INTERNET y ACCESS_NETWORK_STATE. Actualmente no utiliza estos permisos para transmitir datos personales a servidores externos.

6. Recursos del dispositivo

La aplicación no accede a:

  • Ubicación.
  • Cámara.
  • Micrófono.
  • Contactos.
  • Fotos.
  • Vídeos.
  • Archivos del almacenamiento compartido.

Las notificaciones se utilizan únicamente para avisos locales generados en el dispositivo.

7. Cuentas

No es necesario crear una cuenta online, utilizar una contraseña ni iniciar sesión en un servicio remoto.

Necesito Ayuda funciona sin cuentas en la nube y sin registro online.

8. Eliminación de datos

El usuario puede eliminar las solicitudes de ayuda desde las opciones disponibles dentro de la aplicación.

También puede eliminar los datos almacenados por la aplicación desde los ajustes de almacenamiento de Android o desinstalando la aplicación.

No existe una cuenta online que deba eliminarse.

9. Servicios de terceros

Necesito Ayuda no utiliza actualmente servicios de publicidad, analítica, seguimiento ni pagos para recopilar información personal.

La aplicación utiliza componentes estándar de Android y AndroidX, incluyendo Jetpack Compose, Room, DataStore y Lifecycle.

10. Seguridad

Los datos se almacenan localmente en el dispositivo dentro del almacenamiento privado de la aplicación.

La aplicación no incluye intencionadamente contraseñas, tokens de acceso ni credenciales de servicios externos.

11. Menores

Necesito Ayuda no está diseñada específicamente para recopilar información personal de menores.

Cuando corresponda, recomendamos que los menores utilicen la aplicación bajo la supervisión de sus padres, tutores o responsables legales.

12. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando se incorporen nuevas funciones o cambie la forma en que la aplicación trata la información.

La versión actualizada se publicará en esta misma página indicando la fecha de actualización.

13. Contacto

Para cualquier consulta relacionada con la privacidad o el tratamiento de datos en Necesito Ayuda, el usuario podrá utilizar el canal de contacto indicado en la aplicación o en la ficha oficial de Google Play.
